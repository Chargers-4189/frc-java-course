## Preface

> Welcome\!
>
> Hello future Charger programmers. We’re excited to have you on the team and can’t wait to see what you come up with for this 2025 season. Whether or not you have previous programming experience in Java, we’ll help you get to a point where you can program a robot from scratch. We are starting with the basics of coding and Java in this unit. It covers the concepts of programming and syntax in Java. We’re using the resource from the University of Helsinki, the massive open online course (MOOC) on programming, for students to learn Java. This is a self-guided course, however, we will help and guide you if needed. Even though this resource is not updated, it is still a great introduction to Java if you have no experience. If you have any questions or need help, please contact us. We’re always available through email or Discord.
